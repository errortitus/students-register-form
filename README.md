# Student Details Task (Student Management)

A sleek, responsive web application for managing student registration details built with HTML5, CSS3, and modern JavaScript.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## Features

- **Dynamic Student Entry:** Add new student profiles containing Name, Age, Gender, Course, and Email.
- **Interactive Data Table:** Instantly displays registered students in a structured data table upon saving.
- **Dynamic Deletion:** Easily remove specific student records dynamically using DOM manipulation.
- **Responsive Design:** Includes clean CSS styling with modern gradients, layout cards, and custom media queries for mobile-friendly viewports.
